Everything you need

In-game editing

The editor lives directly in your game. Build and modify levels without leaving your runtime.

Native integration

Your game stays in control of its runtime. Polygon hooks in through a small adapter: your scene, your camera, your models.

Readable scene files

Levels are saved as JSON , human-readable, versionable and easy to hand-edit, diff and reload , or shipped as compact binary (.bin). Either file loads the same with poly_load.

From game to level
in three steps.

  1. 1

    Integrate

    Add the editor package to your GameMaker project and hand the editor your world. It takes just a few lines and a small setup.

    Game Create
    poly_create({
    scene: global.my_scene,
    assets,
    cam: global.my_camera,
});
poly_enable(); // opens with F1 (default)
  2. 2

    Build

    Use the in-game editor to create and arrange your 3D scene: place instances, rotate, scale, name and adjust your level.

  3. 3

    Save

    When you’re done, export your level as JSON or binary and load it in your game with poly_load , chunked in the background, deterministically.

    File → Save scene

    ✓ Scene saved
    level1.json

Your levels stay yours.

A. Scene files

Save from a single dialog, with a JSON / Binary radio.

level1.json
{
  "version": 1,
  "seq": 14,
  "assets": { },
  "nodes": [
    {
      "kind": "instance",
      "id": "__PolygonEditor__7",
      "label": "Tree 2",
      "assetId": "models/tree.glb",
      "transform": {
        "position": [1.0, 0.0, 2.0],
        "rotation": [0.0, 0.0, 0.0, 1.0],
        "scale": [1.0, 1.0, 1.0]
      },
      "shadows": { "cast": true, "receive": true }
    }
  ]
}

B. Public API

Control the editor and manage scenes directly from your game. Here are a few of the most useful functions.

oGame
// Boot the editor with your world
poly_create({
    scene: global.my_scene,
    assets,
    cam: global.my_camera,
});

// Load a saved level, no editor involved
var _job = poly_load(my_scene, "__PolygonEditor__/scenes/level1.json", _assets, my_on_create, function (_rep) { show_debug_message("placed: " + string(_rep.placed)); });
poly_load_step(); // call every Step, spawns ~48 nodes per frame
  • Per-frame calls: poly_step(), poly_draw(), poly_draw_ui(); poly_cleanup() shuts down (autosave-if-dirty).
  • Remap every shortcut and camera control through the keys config of poly_create.
