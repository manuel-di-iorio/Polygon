Build worlds inside your game.

A 3D editor for GameMaker. Plug it into your project and build, edit, and save your scenes without leaving your game.

Get it on GitHub Quick start

Everything you need to ship levels

No external tools. Press F1 and edit right inside the running game.

  • In-game editing
    Toggle with F1; the gateway steps the live world while closed.
  • TRS gizmo
    Translate, rotate and scale with world or local axes and drag planes.
  • Outliner + Inspector
    Filter, rename (F2), focus (F), per-axis transform rows.
  • Undo / redo
    Snapshot history with selection restore.
  • JSON scenes
    One descriptor per placement. Save, load, new.
  • Directional shadows
    Per-light setup, preview and global toggle.
  • Snap + nudge
    Position/rotation snap and arrow-key nudge, all undoable.

Requirements

  • GameMaker with GMRT 0.22.4 (from the Package Manager)

Quick start

1. Import the editor package - drag editor.yymps onto the GameMaker IDE to import the scripts. You also need GMRT 0.22.4 (Package Manager), which provides GM3D_* and ImGui.

2. Add the oEditor package object to your game. It is editor-only: your game hands over a runtime adapter, then creates it (full working example in objects/oGame). Load each model once, register it with a unique name: 

// Game Create
var assets = {};
assets[$ "tree.glb"] = { model: my_load_model("tree.glb") };
assets[$ "rock.glb"] = { model: my_load_model("rock.glb"), label: "Rock" };  // optional display label

poly_create({
    scene: global.my_scene,
    assets,
    cam: global.my_camera,
    on_create: my_on_create,  // assign shaders to freshly spawned nodes
});

// Game Step
if (!poly_is_active()) my_game_step(); // live world only while closed

// Game Draw
if (!poly_is_active()) my_game_render(); // editor shows its own viewport

// Game Clean Up
my_game_destroy();

While the editor is open it works on its own scene copy: what you edit never touches the game world. Save to JSON and reload deterministically with poly_load when the game wants it.

Public API

Function Purpose
poly_create(config) Boot editor state from { scene?, assets?, cam?, on_create?, on_close? }: assets is { key: { model, label?, on_create? } }; owns its scene (empty at boot; the live scene is mirrored as copies on every enable, else camera/sun/env defaults spawn). on_create(node, asset, model, id, label) fires first, then the per-model hook — walk the subtree for model content
poly_step() / poly_draw() Per-frame update (Step) + 3D overlay in Draw GUI (gizmo, selection)
poly_render() Draw-event hook (used by the oEditor Draw event): shader warmup, outline mask + GPU pick
poly_cleanup() Autosave-if-dirty, destroy, cleanup
poly_enable / disable / is_active() Open/close the editor
poly_asset_add(model, kind?, label?, path?, on_create?) / poly_asset_clear() Library entry, identified by relative load path (label is display-only)
poly_actor_destroy(ref) / poly_actor_of(node) Kill a companion and its scene node together (accepts the instance id, the node, or the creation struct); look up the live companion bound to a node
poly_track(kind, asset, node, label?) Import one live game node into the editor scene as a copy (asset is the model path; kind is "instance", "light", "camera" or "environment"); game world untouched
poly_load(scene, fname, assets, on_create?) Load a saved scene into a live game scene (no editor); assets is { key: { model, label?, on_create? } } (same shape as init config); per instance calls global on_create, then the per-model hook, then the companion spawn for Actor-bound models; returns { placed, failed, companions, warnings, placements }

Scene file format

{ "version": 2, "seq": 14, "assets": {...}, "nodes": [...] }, one descriptor per node. assets holds per-model file metadata (e.g. Actor bindings). Every descriptor has a id, a label (display name) and, for instances, an assetId field linking the model: 

{
  "kind": "instance",
  "id": "__PolygonEditor__7",
  "label": "Tree 2",
  "assetId": "models/tree.glb",
  "transform": {
    "position": [1.0, 0.0, 2.0],
    "rotation": [0.0, 0.0, 0.0, 1.0],
    "scale": [1.0, 1.0, 1.0]
  },
  "shadows": { "cast": true, "receive": true }
}

Lights, cameras and the environment carry a light / camera / environment sub-struct (angles in degrees, colors as [r, g, b] 0-255). Directional lights can also carry shadow: { enabled, resolution, distance, normalOffset }.

Shadows

Directional lights support shadow mapping, editable in the Inspector under Shadows; selecting a shadowed light draws its coverage box, and the toolbar Shadows button toggles preview without touching saved values. Every material needs both a Forward and a Shadow shader, assigned per live instance — spawnInto clones do not inherit source assignments, so assign them in your spawn hook. Use the sStatic / sAnimated (+Shadow) shaders from this project.

In-game loading (no editor)

poly_load(scene, fname, assets, on_create?) spawns a saved scene into any live GM3D_Scene. Load and freeze each model once, then pass them as { key: { model, label?, on_create? } } — the key is the asset id (the relative load path, e.g. "models/tree.glb"). Per instance it calls the global on_create(node, asset, model, id, label), then the per-model hook, then the companion spawn for Actor-bound models (configured in the model Inspector, saved as top-level "assets" in the file); the companion receives { node, poly_id, poly_asset, poly_label }: 

var _assets = {};
_assets[$ "models/tree.glb"] = { model: my_load_model("models/tree.glb") };
_assets[$ "models/rock.glb"] = { model: my_load_model("models/rock.glb") };
var _rep = poly_load(my_scene, "__PolygonEditor__/scenes/level1.json", _assets, my_on_create);
// _rep = { placed: 9, failed: 0, companions: 2, warnings: [], placements: [...] }
// After loading, assign Forward+Shadow shaders per spawned node (see Shadows above).

Controls

Input Action
Ctrl + W Close editor
1 / 2 / 3 / 4 View / Move / Rotate / Scale tool
Left-drag model (Models panel) Spawn into the scene
Left-click / drag Select (additive rectangle with drag)
Alt + left-drag Orbit around the current view point
Right-drag + W/S forward/back, A/D left/right, Q/E down/up, Shift Fly camera; wheel adjusts fly speed
Alt + right-drag / wheel Zoom view
Middle-drag Pan view in screen space (around the selection if any)
F (or double-click in Scene) Focus selection
F2 Rename (labels are display-only)
Arrows Nudge selection on the ground plane (undoable)
Ctrl (held while dragging) Temporary snap
Del Delete selection
Ctrl+D Duplicate
Ctrl+S / Ctrl+L / Ctrl+N Save / Load / New scene
Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) Undo / Redo
Esc Cancel gesture / rename / close dialog
